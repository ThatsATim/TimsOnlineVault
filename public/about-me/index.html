Tim's vault

As the name of the site would suggest, my name is Tim. Passionate about the industry we call IT.

I have been involved in projects surrounding minecraft servers for a decade now. This has included everything from server administration to server development.

I started moderating minecraft servers in 2013. Hosted my own little servers throughout 2015–2019. Became an administrator of an existing server in 2019. Merged with that server in 2020, and we stayed online for about 5 years.

During those years, we had even experimented with our own server plugin development. This brought me to my introduction to the development side of this industry. All this has made it, so I am very interested in the DevOps field with its focus on Linux, infrastructure and clean systems using code.

Now I am looking to spread my wings and take what I have learned to apply it to the broader IT industry.

This website is a bit of a passion project. I am looking to document what I know so far and maybe help others along the way. So this is not a course or some training material. What this is in reality is a collection of my knowledge and experiences.

Please don’t hold any of this as a source of truth or a source of wisdom. Seeing, as I’m writing all of this by myself as a student, this project will have mistakes and errors.

I had started on a similar project for just myself in Obsidian for just one networking class I had. This is an extension of that project and a way to share with people that which I have poured quite a lot of time into.
